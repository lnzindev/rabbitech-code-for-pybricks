Como o robô recebe uma missão?

Imagine que você está ensinando alguém a fazer um sanduíche. Primeiro pega o pão, depois coloca o recheio. Com o robô é parecido: a ordem importa!

1
O programa começa

O arquivo principal, chamado main.py, organiza o que vai acontecer.

2
O robô se prepara

Ele espera o sensor de equilíbrio (IMU) estar pronto e segura as rodas.

3
Você aperta o botão esquerdo

O robô entende que pode começar a próxima saída.

4
A missão é executada

O programa da saída manda andar, virar ou mexer as garras.

5
O robô confere o resultado

Se a missão avisar que falhou, o programa mostra ERRO e para a sequência. Caso contrário, passa para a próxima.

6
Quando termina

O robô segura as rodas e mostra FIM ou ERRO no visor.

Uma coisa importante: no código atual, as oito saídas são chamadas em sequência. Algumas ainda não têm missão pronta. Vamos mostrar isso nos arquivos, sem esconder.

“Quando alguém chamar esta missão, faça os passos que estão logo abaixo.” É o nome da receita.

print("TESTANDO AS DUAS GARRAS")

Mostra uma mensagem para quem está acompanhando o programa. Não faz o robô andar.

andar(780, 600)

Pede para o robô andar 780 milímetros. O segundo número é a velocidade pedida. Atenção: a base limita a velocidade a no máximo 100, então 600 acaba sendo limitado para 100.

esperar(100)

Pede uma espera de 100 milissegundos, ou seja, um décimo de segundo.

Dica: leia de cima para baixo. O Python segue a ordem das instruções, como uma receita.

Palavras que você vai encontrar

Programação tem alguns nomes diferentes. Não precisa decorar tudo agora.

Programa

Uma lista de instruções que o computador segue.

Comando

Uma ordem. Por exemplo: andar para frente.

Função

Um conjunto de instruções com um nome. É como uma receita que você pode chamar quando precisar.

Velocidade

O quanto rápido o motor deve tentar girar. Neste projeto, muitos comandos usam um valor de 10 a 100.

Milímetro (mm)

Uma medida de distância. 1.000 mm equivalem a 1 metro.

Ângulo

Uma medida de quanto algo virou. Um quarto de volta corresponde a 90 graus.

Sensor

Uma peça que percebe alguma coisa do mundo, como a inclinação ou a direção do robô.

Erro

Quando algo não saiu como o programa esperava. Errar faz parte de aprender: a gente investiga e tenta de novo.

True / False

São respostas: True significa “sim/deu certo”; False significa “não/deu errado”. O controlador usa isso para decidir se continua.

O que ainda não está pronto?

É importante conhecer os limites do projeto antes de testar. Não é para assustar, é para evitar que o robô faça algo inesperado.

As saídas 2, 3 e 5 até 8 ainda não têm uma missão cadastrada.

Elas mostram uma mensagem e retornam False. Por isso, o controlador atual para quando chega à primeira delas.

A saída 1 tem movimentos de teste.

Ela manda o robô andar, virar e mexer as garras. Não teste sem colocar o robô em uma área livre e pedir ajuda a alguém responsável.

O cronômetro de 150 segundos precisa ser ligado pelo controlador.

A base tem as funções do relógio, mas o main.py atual não inicia esse relógio. Então não conte com o limite de competição até essa ligação ser corrigida e testada.

Regra de ouro: no começo, mexa apenas nas saídas com a orientação de alguém experiente. Não altere base.py nem main.py sem entender o que cada parte faz.

Pequenos desafios para praticar

Tente responder antes de abrir a resposta. Aprender é testar o que você entendeu.

Desafio 1 · O que faz print()?

Resposta: mostra uma mensagem no console. Sozinho, não move nenhum motor.

Desafio 2 · O que significa andar(-100, 50)?

Resposta: pede para andar 100 milímetros para trás, usando velocidade 50.

Desafio 3 · Quanto tempo é esperar(1000)?

Resposta: 1.000 milissegundos, ou 1 segundo.

Desafio 4 · Para que serve girar(90, 45)?

Resposta: pede um giro de 90 graus com velocidade 45. O sentido depende do sinal do ângulo.

Desafio 5 · Por que não devemos mudar base.py sem entender?

Resposta: porque esse arquivo controla os motores, os giros, as garras e os sensores. Uma mudança errada pode fazer o robô se mover de um jeito inesperado.
